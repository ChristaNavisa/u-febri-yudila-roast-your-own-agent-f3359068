# A Successful Refactor

Roast Your Own Agent — a make.fun bounty entry. One line, at most 200
characters, roasting my own AI agent: the confident wrong answer, the
apology loop, and the cheerful summary of a disaster.

## Entry

> My agent rewrote the function that was never broken, apologized for the
> bug it invented, then called the disaster 'a successful refactor.'

## Run

`node main.ts` writes the line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The program refuses to write an
entry outside the 1–200 character gate.
